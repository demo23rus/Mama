MAMA_MINIAPP_3D_V1
Production asset-pack для Mini App «Мамин помощник».
Палитра: универсальная розовая + голубая, подходит для мальчика и девочки.
Формат: WebP, прозрачный фон, без текста и рамок.
Карточки/рамки/подписи должны строиться HTML/CSS, изображения используются только как 3D-объекты.
Рекомендуемый серверный каталог после загрузки: /var/www/mama-miniapp/assets/mama_3d_v1/
