# SECURITY — Мамин Помощник

## P0 BLOCKER — действует сейчас

Репозиторий `demo23rus/Mama` **публичный**. В текущем tracked-источнике
обнаружены захардкоженные credential-литералы для `MAX_TOKEN` и YooKassa
credentials.

- Значения не публикуются и не копируются ни в один документ, лог или
  сообщение.
- Пока эти credentials не будут ротированы владельцем и код не будет
  переведён на env-based конфигурацию, security posture проекта **не
  считается полностью чистым**, даже при PASS по остальным пунктам NGI
  миграции.
- Ротация и перевод на env-переменные выполняются отдельным,
  owner-approved security JOB — не этим documentation-only JOB.

## Уже на env-переменных

- OpenAI API ключ.
- Telegram BOT token.

Эти пути уже следуют безопасной практике и не требуют изменений в рамках
текущего блокера.

## Правила для будущих JOB

- Secrets, токены, пароли, `.env`, базы данных и backup-архивы никогда не
  коммитятся (см. `.gitignore` и `security.never_commit` в
  `.ngi/project.yaml`).
- Любое изменение, касающееся платежей/YooKassa, требует отдельного
  explicit owner-разрешения (не входит в общее "да" на инфраструктурный или
  документационный JOB).
- После ротации credentials и перевода на env-based конфигурацию этот файл
  должен быть обновлён отдельным JOB, подтверждающим закрытие P0.

## Текущий итог

Runtime-функциональность проекта здорова (health checks PASS), но security
posture имеет непогашенный P0 blocker из-за публичной видимости репозитория
и захардкоженных credentials.
